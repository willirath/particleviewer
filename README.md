# particleviewer

Tools for looking at particle trajectory stores (Zarr).

| directory | |
|---|---|
| [`kelp-live/`](kelp-live) | live terminal view of a growing kelp Zarr trajectory store |
| [`trajshade/`](trajshade) | interactive datashader line aggregations of trajectory stores |

Each is its own uv project: `cd <dir> && uv sync`.
